Washout-thrust BTC bot. It waits in cash for a sharp washout — the worst 15-minute return over the last 45 bars at most -85 bps — then buys the thrust back up when the current 15-minute return reaches +15 bps, with the whole cash. It exits on a +120 bps take-profit, a -60 bps stop-loss, a 30 bps trailing stop below the best close since the fill, or a stall exit if the trade is still under +15 bps eight bars after the fill, then waits 30 bars before the next trade. A softer -60/+10 entry applies after bar 1200 if nothing has traded yet.
